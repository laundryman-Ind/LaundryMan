3. Reproduction rules (APK / WebView)

  • Do not scale the whole app, stretch a 9:16 design vertically, or hardcode viewport-sized dimensions like height:855px; width:481px.
  • Derive component geometry from available width + fixed design proportions: %, fr, minmax(), clamp(), aspect-ratio, flex/grid gaps.
  • Fixed-size elements (buttons, icons, inputs, badges, radii, paddings) keep their px values; fluid containers (cards, columns) fill the width with the same internal padding and gaps.
  • Respect safe areas: bottom:calc(16px + env(safe-area-inset-bottom)); keep the nav fixed and never covered by content.
  • Cards keep their proportions; text must never clip (fold narrow cards into wider spans below 480px if needed).
  • Height and width are independent — a taller phone changes nothing but the scroll length.
